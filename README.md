# Godla Sravani - Responsive Personal Developer Portfolio

This project was created as **Task 1: Responsive Personal Developer Portfolio** for a Web Development internship.

## Features
- Responsive design for desktop, tablet and mobile
- About, skills, projects, education and contact sections
- Mobile navigation menu using JavaScript
- GitHub and LinkedIn links
- Clean semantic HTML
- Responsive CSS layout
- No external frameworks required

## Technologies
- HTML5
- CSS3
- JavaScript

## Projects Featured
1. Laundry Booking Application
2. Student Result Management System

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a browser.
